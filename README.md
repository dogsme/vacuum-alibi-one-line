One line, at most 200 characters, in which a robot vacuum explains why it missed a spot — deadpan, a little smug about its sensors, with the punch at the end.

## The line

> I skipped that spot on purpose: my lidar filed it under 'haunted', and my warranty does not cover ghosts.

## How it works

`main.py` (Python 3.13) writes exactly that one line to `/output/entry.txt` in UTF-8. Nothing else is written, read from the network, or needed at run time.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
